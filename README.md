# Elliot Lowery Engineering Portfolio

A simple static project website built with HTML and CSS.

## Files

- `index.html`: Website content
- `styles.css`: Website styling

## Local preview

Open `index.html` in your browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `styles.css`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Save.
7. GitHub will give you a public website link after it deploys.

## Edit later

Most text lives in `index.html`. Colors and layout live in `styles.css`.
