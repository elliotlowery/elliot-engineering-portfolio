Project Detail

FPGA Bop-It

Used Verilog on an FPGA to recreate a Bop-It style game with multiple interactive features, including physical movement, voice prompts, and several different buttons for user input. The project combined digital logic, hardware design, and programming to create an interactive game system.

Overview

The project used an FPGA and Verilog to recreate a Bop-It style electronic game. The system included several different user inputs and interactive features, including movement, voice prompts, and multiple buttons. Digital logic was used to control the game behavior and respond to the player's actions.

What I Did

I used digital logic design and Verilog to develop the state machine that controlled the overall behavior of the game. I was also heavily involved in debugging the system and resolving issues between the different hardware and logic components. Additionally, I worked on integrating the FPGA board's microphone and accelerometer, allowing the game to respond to sound and physical movement as part of the gameplay.

Technical Focus

  • Verilog
  • FPGA Development
  • Finite State Machine Design
  • Digital Logic
  • Accelerometer Integration
  • Microphone Integration
  • Hardware Debugging

What I Learned

This project strengthened my understanding of how digital logic and Verilog can be used to control a complete interactive hardware system. I gained experience debugging a system where multiple hardware components and logic blocks had to work together reliably. Integrating the microphone and accelerometer also gave me experience working with hardware inputs beyond basic buttons and switches.
