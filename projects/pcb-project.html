Project Detail

Terrier Motorsport Intro PCB Project

A PCB project representing a racecar vehicle control center, focused on precharge logic, motor activation, temperature monitoring, and safe electrical system design.

Overview

This project was completed as part of BU Terrier Motorsport onboarding. The goal was to design and program a PCB that modeled important control center behavior for a racecar electrical system.

Technical Focus

  • System precharge logic
  • Motor activation logic
  • Temperature monitoring using a DHT11 sensor
  • 16x2 LCD display output
  • LV/HV isolation considerations
  • Voltage step-down circuitry for voltage greater than 12V

Tools Used

PCB Design Arduino DHT11 LCD Display Circuit Design

What I Learned

This project strengthened my understanding of how embedded logic, circuit design, and safety constraints interact in vehicle electronics.
