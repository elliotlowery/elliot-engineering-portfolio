Project Detail

Rastic X Hackhardware Robot Challenge

A one-week hardware challenge to design a robot capable of picking up magnetic coins. The project earned 3rd place.

Overview

The challenge was to quickly design and build a robot that could pick up magnetic coins. I worked on the picking-up mechanism and helped translate the design idea into a working robot system.

Technical Focus

  • Magnetic pickup mechanism
  • Servo motor control
  • Arduino programming
  • Rapid prototyping
  • Physics-based design decisions

Tools Used

Arduino Servo Motor Mechanism Design Physics Robotics

What I Learned

This project emphasized fast design iteration, tradeoffs between simple and reliable mechanisms, and the importance of testing hardware early.
