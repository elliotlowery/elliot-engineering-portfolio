Project Detail

Temperature Sensor

A semester-long temperature monitoring box that combined mechanical design, electrical components, Arduino programming, and user-facing output.

Overview

This project involved building a temperature monitoring box that reads and displays temperature. The final design combined mechanical housing, electrical wiring, sensors, LEDs, and an LCD screen.

Technical Focus

  • Arduino temperature reading logic
  • LCD screen output
  • LED status indicators
  • Mechanical housing design
  • 9V battery holder design

Tools Used

Arduino OnShape 3D Printing LCD Display LEDs

What I Learned

This project helped connect physical design choices with electrical system behavior, especially in building a complete object rather than only a circuit.
